# IMA 知识库搜索策略参考

## 高效搜索关键词策略

### 1. 主题发散法

围绕核心主题，发散多个相关关键词：

**示例：用户要找"生态环境破坏相关法规"**

核心词：`生态环境 破坏`
扩展词：`环境保护 生态保护 环境污染 生态破坏 环保法规`
长尾词：`生态环境法 环境保护条例 生态红线 环境影响评价`

### 2. 分类搜索法

对于分类信息，用分类名称+具体条目的方式：

```
# 找分类
搜索："分类" "类型" "种类"

# 找具体条目
搜索：分类名称 + 具体内容
```

### 3. 问答对法

模拟用户可能提问的方式：

```
原问题：缺氧怎么分类？
搜索词：
- "缺氧 分类"
- "低张性缺氧"
- "血液性缺氧"
- "循环性缺氧"
- "组织性缺氧"
```

## 内容拼凑原则

### 收集阶段
- 不放过任何相关关键词的搜索结果
- 同一内容用多个不同角度关键词搜索
- 注意 `media_id` 相同的条目，它们来自同一文档

### 整理阶段
1. **按来源分组**：同 `media_id` + `title` 的片段归类到一起
2. **去除 HTML 标签**：高亮内容中的 `<em>...</em>` 是高亮标记，去除后阅读
3. **去重**：相同/相似内容只保留一条
4. **标注来源**：每条内容标注来自哪个文件

### 输出格式

```markdown
## 相关内容整理

### 一、[主题分类名称]

**来源**：[文件名.pdf]

> [高亮片段内容1]
> 
> [高亮片段内容2]

---

### 二、[另一主题]

**来源**：[另一文件.pdf]

> [相关内容]
```

## 常见问题

### Q: 搜索返回空结果
A: 知识库中可能没有相关内容，换同义词再搜；或确认知识库 ID 是否正确

### Q: 返回"没有权限"
A: 机器人未被添加到该知识库，需要用户手动添加

### Q: 高亮片段太碎片化
A: 用更具体的长尾关键词再搜，如"不是"环境"而是"生态环境破坏防治""

### Q: 同一内容多个片段
A: 正常现象，说明该内容被多个关键词匹配到，保留最完整的一条即可
